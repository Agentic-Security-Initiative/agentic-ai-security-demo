How to create the token

  1. Sign in to GitHub with the account that was given access, then open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and choose Generate new token.
  2. As Resource owner, choose the organization that owns the repository; under Repository access, choose Only select repositories and pick that repository.
  3. Under Permissions, set Contents to Read-only. No other permission is needed.
  4. Choose a short expiration, generate the token, and paste it into the sign-in page of a section.

If you were added to the repository as an outside collaborator, not as a member of the organization that owns it, GitHub does not offer that organization as resource owner, and a new fine-grained token may wait for an owner's approval. In the first case, create a classic token with the repo scope instead, with the shortest expiration, and delete it when you are done: a classic token can read and write every repository your account can.

A token entered in one section serves the others until the tab is closed. It stays in this browser tab and is sent only to api.github.com; signing out forgets it at once.
