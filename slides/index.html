Private presentation

Sign in with GitHub to view it

This page shows a presentation kept in a private GitHub repository. GitHub decides who sees it: paste a personal access token of a GitHub account that can read that repository.

Sign in to GitHub and create a token

How to create the token
  1. Sign in to GitHub with the account that was given access, then open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and choose Generate new token.
  2. As Resource owner, choose the owner of the repository; under Repository access, choose Only select repositories and pick that repository.
  3. Under Permissions, set Contents to Read-only. No other permission is needed.
  4. Choose a short expiration, generate the token, and paste it above.

If you were invited as a collaborator to a repository owned by a personal account, GitHub does not offer that repository to fine-grained tokens. Create a classic token with the repo scope instead, with the shortest expiration, and delete it when you are done: a classic token can read and write every repository your account can.

The token stays in this browser tab and is sent only to api.github.com. Closing the tab forgets it, and so does signing out. Revoking the token, or your access to the repository, takes effect at once.
